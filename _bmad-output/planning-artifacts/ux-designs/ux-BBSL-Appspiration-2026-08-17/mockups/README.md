# Mockups

Six artboards, all at 375px in the settled house style. **Where any of these disagrees with [DESIGN.md](../DESIGN.md) or [EXPERIENCE.md](../EXPERIENCE.md), the spines win.**

| File | Shows |
|---|---|
| `Positions.dc.html` | **Your Positions** — the landing surface, grouped as the wake-up session actually asks. Includes the empty state. |
| `Board.dc.html` | **Bid Board** — five auction states, position filters, sticky Maximum Bid strip. |
| `Auction.dc.html` | **Auction detail** — full attributed bid history, disabled bid control with its reason stated. |
| `Commissioner.dc.html` | **Commissioner control class** — Manager control vs Commissioner control, the mandatory reason sheet, and the paused state. |
| `Teams.dc.html` | **Teams index** (CAP-20 / FR-39) — all 30 Teams by remaining slots and cap position, sorted alphabetically, with the League Median. Seven rows shown of thirty. |
| `House.dc.html` | **House style reference** — board card in three states, Maximum Bid panel, refusal, persistent strip. |

These are Design Component artboards (`.dc.html`), not standalone web pages — they reference a runtime injected by the canvas and will not render if opened directly in a browser.

**View them at:** https://claude.ai/code/artifact/53dcf7ff-c80d-4a4d-a75d-28c950a12e96 — page *Key screens*. The *Direction study* page holds the three original directions the house style was drawn from, with notes on what was taken from each.
